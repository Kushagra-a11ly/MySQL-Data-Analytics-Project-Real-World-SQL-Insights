## 📘 Overview

This repository contains a comprehensive SQL query designed to analyze pizza sales
using a real-world dataset. It demonstrates practical SQL analytics skills by extracting
meaningful insights on sales performance, customer behavior, and operational trends.
Unlike a tiered approach, this single query incorporates **basic**, **intermediate**,
and **advanced** SQL techniques in one unified, executable workflow.

---

## 🎯 Purpose

- Analyze pizza store operations and sales trends
- Demonstrate practical SQL analytics skills on a real dataset
- Provide actionable insights to support business decisions across product demand,
  customer preferences, and revenue analysis

---

## 📝 Query Description

The SQL query in this repository covers all levels of complexity:

| Level | Techniques Used |
|---|---|
| **Basic** | `SELECT`, `WHERE`, `ORDER BY`, and basic aggregations |
| **Intermediate** | `JOIN`s across multiple tables, `GROUP BY`, and aggregation functions to summarize sales data |
| **Advanced** | Subqueries, CTEs, window functions, and complex aggregations for deeper business insights |

> This unified query is designed to cover all levels of SQL complexity
> in a single, executable workflow.

---

## 🚀 How to Use

1. Open your MySQL client or IDE (**MySQL Workbench**, **VS Code**, etc.)
2. Copy the SQL query into the editor
3. Execute the query
4. Analyze the results to derive insights about sales trends, customer behavior,
   and operational efficiency
